Hacker Chapter 3: Burp Suite

What is Burp Suite?

Burp Suite is a web security testing tool. It allows you to see, inspect, and modify the requests that your browser sends to a website. It is commonly used by penetration testers.

How to Use Burp Suite

  1. Open Burp Suite and start a temporary project.
  2. Open Burp's built-in browser.
  3. Go to a website you are authorized to test.
  4. Open Proxy → HTTP history to see the requests.
  5. Click a request to inspect its headers, URL, parameters, and response.
  6. Send a request to Repeater to test changes manually.

Important Features

Feature Use
Proxy Intercept and inspect browser traffic.
HTTP History View requests and responses.
Repeater Modify and resend requests manually.
Intruder Automate repeated requests for authorized testing.
Decoder Encode and decode data.

Simple Example

Visit a test website using Burp's browser. Find your request in Proxy → HTTP history, right-click it, and choose Send to Repeater. In Repeater, you can change a harmless parameter and click Send to see how the server responds.

Important: Only use Burp Suite on websites, applications, or cybersecurity labs where you have permission to test.
