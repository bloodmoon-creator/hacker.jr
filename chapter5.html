Hacker Chapter 5: Web Fundamentals

What is HTTP?

HTTP (HyperText Transfer Protocol) is used for communication between a web browser and a web server. HTTPS is the encrypted version of HTTP.

Request & Response

When you visit a website, your browser sends a request to the server. The server processes it and sends a response back. 

Browser → Request → Server
Browser ← Response ← Server

Important HTTP Methods

Method Purpose
GET Requests information from a server.
POST Sends data to a server.
PUT Updates or replaces data.
DELETE Requests that data be removed.

Common Status Codes

Code Meaning
200 Success
301 Redirect
403 Forbidden
404 Page not found
500 Server error

Cookies

Cookies are small pieces of data stored by a browser. Websites can use them to remember information such as login sessions and preferences.

Why Does This Matter?

Understanding HTTP, requests, responses, cookies, and status codes makes tools like Burp Suite much easier to understand.
