Hacker Chapter 6: Networking Basics

What is a Network?

A network is simply a group of devices connected together so they can communicate and share information. Your computer, phone, printer, and other devices can all communicate through a network. The internet is basically a huge collection of networks connected together.

IP Address

An IP address is an address used to identify a device on a network. Think of it like the address of a house. When one device needs to communicate with another device, the IP address helps it know where to send the information.

Example: 

192.168.1.10

Ports

A port can be thought of as a numbered doorway into a device. Different services commonly use different ports. For example, web traffic commonly uses ports 80 and 443.

Port Common Use
22 SSH
53 DNS
80 HTTP
443 HTTPS

TCP and UDP

TCP and UDP are two different ways of sending information across a network. TCP focuses on reliable delivery, meaning it checks that information arrives correctly. UDP is faster and has less overhead, but it does not provide the same delivery guarantees.

DNS

DNS stands for Domain Name System. It translates easy-to-remember domain names into IP addresses. This means you can type a website name instead of having to remember its numerical IP address. 

example.com → IP address

Router

A router connects networks together and directs traffic to the correct destination. Your home router, for example, connects your local devices to your internet connection.

Client and Server

A client is a device or program that requests something. A server is a computer or program that provides it. When you open a website, your browser acts as the client and the website's server sends the requested information back.

Understanding these basic concepts makes tools such as Nmap and Burp Suite much easier to understand because you now know what devices, ports, services, and web traffic actually are.

Remember: Only test networks and devices that you own or have permission to test.
