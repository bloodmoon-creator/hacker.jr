Hacker Chapter 2: Nmap

What is Nmap?

Nmap (Network Mapper) is a tool used to discover devices, open ports, and services on a network.

Important Commands

Command Purpose
nmap 192.168.1.10 Basic scan
nmap -sV 192.168.1.10 Detect service versions
nmap -O 192.168.1.10 Try to detect the operating system
nmap -p 80,443 192.168.1.10 Scan specific ports
nmap -p- 192.168.1.10 Scan all TCP ports
