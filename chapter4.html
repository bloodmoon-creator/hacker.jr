Hacker Chapter 4: Linux Basics

Why Linux?

Linux is widely used in cybersecurity because it gives you powerful command-line tools and control over files, processes, and networks.

Important Commands

Command Purpose
pwd Shows your current directory.
ls Lists files and folders.
cd folder Moves into a folder.
mkdir folder Creates a new folder.
touch file.txt Creates a new file.
cat file.txt Displays the contents of a file.
cp file.txt backup.txt Copies a file.
mv old.txt new.txt Moves or renames a file.
grep "word" file.txt Searches for text inside a file.

Basic Example

pwd
ls
mkdir practice
cd practice
touch notes.txt
cat notes.txt

These commands let you find where you are, view your files, create a folder, enter it, and create a file.

Tip: Practice these commands in your own Linux machine or an authorized cybersecurity lab.
